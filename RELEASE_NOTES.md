## Возможности

- Запись выпитой воды и просмотр итога за текущий день.
- Настраиваемая дневная цель, процент выполнения и сообщение о достижении.
- Удаление с подтверждением.
- Напоминания через 30, 60 или 120 минут.
- Автоматическое сохранение журнала, цели и настроек в браузере.

## Запуск

Скачайте **Source code (zip)**, распакуйте архив и откройте `index.html` в Chrome или Edge. Напоминания отображаются в открытой активной вкладке.

## Проверки

JavaScript проверен в GitHub Actions. Пройдены 17 автоматических тестов и сценарии в Chrome и Edge на Windows 11.
