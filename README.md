## Цель работы

Составить требования к приложению и оформить их в GitHub Wiki и Issues.

## Описание приложения

Приложение позволяет записывать выпитую воду, задавать цель на день и получать напоминания. На главном экране отображаются записи, дневная сумма и процент выполнения цели. Данные сохраняются в браузере.

## Основные функции

- Добавление объёма выпитой воды в миллилитрах.
- Установка дневной цели.
- Просмотр результата за текущий день.
- Удаление ошибочной записи.
- Настройка напоминаний.
- Автоматическое сохранение записей и настроек.
