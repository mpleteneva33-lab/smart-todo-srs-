# Процесс разработки трекера потребления воды

Лабораторная работа №3. Вариант 24. Исполнитель — [@mpleteneva33-lab](https://github.com/mpleteneva33-lab).

## Приложение

Трекер записывает объём выпитой воды и время записи, показывает дневную сумму и процент от цели. Запись можно удалить после подтверждения. Цель сохраняется между днями. Напоминания с интервалом 30, 60 или 120 минут показываются в открытой активной вкладке.

Приложение написано на HTML, CSS и JavaScript. Журнал и настройки хранятся в `localStorage`.

- `index.html` — формы, дневная сводка, журнал и настройки.
- `style.css` — оформление и адаптация под узкий экран.
- `model.js` — валидация, расчёты, хранилище и таймер.
- `script.js` — обработка действий и обновление страницы.
- `tests/` — автоматические проверки.

## Автоматические проверки

GitHub Actions запускается при пуше в `main` и в Pull Requests в эту ветку. CI проверяет наличие файлов, синтаксис JavaScript и запускает 17 тестов Node.js. Тесты охватывают проверку ввода, дневные итоги, сохранение, смену даты, цель и таймер.

Локальный запуск с Node.js из корня репозитория:

```sh
node --test tests/*.test.cjs
```

Успешные запуски CI доступны для [PR #31](https://github.com/mpleteneva33-lab/smart-todo-srs-/actions/runs/45954644631), [PR #32](https://github.com/mpleteneva33-lab/smart-todo-srs-/actions/runs/45954811511) и [PR #33](https://github.com/mpleteneva33-lab/smart-todo-srs-/actions/runs/45955138799).

## Проверка в браузерах

В Chrome и Edge на Windows 11 проверены ошибочный ввод, расчёт 38% для 750 мл из 2 000 мл, результат свыше 100%, отмена и подтверждение удаления, перезагрузка, смена дня и напоминания. При ширине 360 пикселей горизонтальной прокрутки не было. При имитации недоступного хранилища появилось сообщение «Не удалось сохранить данные».

Добавление 1 000-й записи с обновлением итога заняло 109 мс в Chrome и 111 мс в Edge на компьютере с 16 ГБ ОЗУ. Проверка на машине с 2 ГБ ОЗУ из ТЗ ещё требуется.
